## Estrutura

Responsável por armazenar as configurações e arquivos relacionados aos projetos.

### projc.[NOME_DO_PROJETO]

Pasta responsável por identificar e armazenar os arquivos de um projeto específico.

**Estrutura:**

* `config.json`

  * Arquivo responsável por armazenar as configurações do projeto.

* `modelos/`

  * Pasta responsável por armazenar os modelos associados ao projeto.
